# WORKBENCH REQUIREMENTS

## 产品目标
Motion Atlas 341 是公开的代码动画创作工作台：让用户从 341 条真实风格原文中选择、组合、填写需求，导出可执行的 DeepSeek Harness Prompt 或可解压 ZIP。公网页面负责选择与导出，真正的动画制作在本地有权限的 DSH 中完成。

## 已实现
- 341 条唯一风格；10 个系列；193 张真实参考图。
- 编号/中文/英文/关键词/原文搜索；系列筛选；仅有图；收藏；多选；已选视图。
- 风格详情：简介、推荐场景、关键词、原文路径、SHA256、完整 Markdown、许可/来源、原图查看、复制原文。
- 缺失原文的 8 条（M14/M15/M16/M17/M26/M35/M39/M40）明确标注“不完整”；加入任务时二次确认。
- 任务编辑：名称、主题、完整文案、观众、核心意思、事实、时长、画幅、分辨率、帧率、字幕、音乐、音效、旁白、角色、组合方式、输出、特别要求、禁止事项、阶段、ZIP 模式。
- 风格角色：主视觉、动态语言、辅助特效、排版/配色、特定场景、辅助参考。
- 组合模式：全片统一、分镜不同、主风格+辅助特效、由 DSH 安排；冲突提示，不擅自丢弃选择。
- 右侧摘要：主风格、辅助、规格、声音、阶段、预计交付、缺失信息。
- 复制/下载完整 Prompt；真实 ZIP（轻量/完整离线模式）；任务草稿 local storage。
- 示例 B3+O63 真实 ZIP；《完成之后》迁移到 `showcase/`。

## 边界
- 公网不执行 SSH/Shell/PowerShell/Python/DSH Agent 命令。
- 用户文案默认只在浏览器处理；不保存到服务器。
- 不自动进入 final；不自动部署；不生成付费第三方请求。

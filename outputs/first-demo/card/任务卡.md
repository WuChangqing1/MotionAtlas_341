## 1. 全文理解

- **一句话主旨**：机器人把动作做完了，不等于任务完成了；任务完成由结果状态对约束的满足来定义，并由独立检查给出证据。
- **观众理解变化**：从“抓取—移动—放下干净利落 = 任务完成”，变成“动作只是过程；位置、朝向、贴合这些结果约束，加上独立验证，才定义完成”。
- **情绪起点 → 转折 → 落点**：自信（任务清楚）→ 顺畅（执行利落）→ 满意（假完成章）→ 疑惑（一条缝）→ 冷峻（VLM 证据）→ 确定但不庆祝（纠正指令）。
- **不能改的事实**：
  1. 机器人抓取物体并放到目标位置；
  2. 动作看起来完成；
  3. 视觉检查发现摆放不符合任务要求；
  4. VLM 验证确认任务失败；
  5. 系统给出纠正反馈。
- **全文结构**：提出（任务与约束）→ 执行（抓取/放置）→ 伪结论（完成章）→ 发现（目检）→ 反转/证据（VLM）→ 纠正（可执行指令）→ 落点（动作完成 ≠ 任务完成）。
- **观众进入前知道什么**：机器人会抓取、搬运、放置；看到“完成”信号会默认任务结束。
- **看完多知道什么**：完成信号不是证据；结果状态和验证才是。失败可以被指出、量化和纠正，不需要演成“机器人很笨”或“VLM 万能”。
- **可持续变形的载体**：一页装配日志 + 同一颗齿轮 + 同一枚“完成/未完成”印章。全片不换世界，只换状态。

### 4.2 风格卡：B3 粒子聚形

- **编号 / 名称 / kind**：B3 · 粒子聚形 · `prompt`
- **路径**：`style-library/风格提示词/A-G_代码样片/B3_粒子聚形.md`
- **SHA256**：`2a784814e01c2ca003b6c5c2ddb1cffb84b0f57f45e6416543b95eecaaf66af1`
- **字节 / 行数 / 库版本**：5627 / 73 / `4a96742d3643538227c849a593380f25b66f001f613ed2915dd20f3dfd216f5a`
- **必须保留的语法**：
  1. 同一批粒子共享身份，在第 i 个目标点之间迁移，不是每帧重新随机；
  2. 二次贝塞尔弧线：先炸开、再汇聚，粒子走弧线而不是直线插值；
  3. 停—变—落的节奏：e=0 停住，smoothstep 变形，e=1 落定；
  4. 加法发光 `globalCompositeOperation='lighter'`；
  5. 拖尾不保存历史，用同一位置函数在 t−0.045 重算；
  6. 种子随机（mulberry32），同一 t 永远同一画面；
  7. 每颗粒子的角度、幅度、相位、闪烁频率、大小、光晕是启动时固定参数。
- **译成本片规则**：
  - 粒子数从 5000 降到 500–3500，按镜头分配；峰值在 S05，避免 1080p 下糊成一片。
  - 目标形状从“心/房子/人/汉字”换成工程目标：A 座环、规格虚影、扫描幕、接触图、纠正幽灵、落点下划线。
  - 周期从 4.8 秒循环改成事件驱动：每个镜头有自己的 gather / hold / dissolve 窗口，不再循环。
  - 背景从 `#07080C` 星空改成纸面；只在 S05 把环境压暗到 0.62，让粒子短暂成为主光源——这是 B3 暗场语法在叙事内的唯一合法出现。
  - 颜色从粉/橙/蓝/象牙改成象牙 `#F6EBD0`、赭金 `#E8C98A`、铁锈 `#B4553F`；不用彩虹、不用霓虹蓝。
  - 字幕从 46px 屏幕下方改成纸上墨线标注；粒子不参与汉字采样，避免字体依赖和“粒子字”糊读。
  - 保留 `lighter`、两段拖尾（性能考虑从 3 次降到 2 次）、微动、同一 id 目标迁移。
- **不保留**：心/房子/人/汉字四个形状、220 颗暗星、19.2 秒循环、固定 (960,520) 中心、46px 字幕、深空背景。
- **依赖**：原生 Canvas 2D，无外部库、无字体文件、无图片；不引用 DEMO.md。`dependency_candidates=[]`，但 `dependency_audit_complete=false`，本片按独立实现处理。
- **风险**：浅色纸上加法发光容易“糊”或“发灰”。先用低 alpha（0.35–0.75）、预渲染 sprite、暗场三件事控制；若仍糊，减粒子数而不是加 bloom。

### 4.4 融合规则（为什么不是简单拼接）

1. **同一个基底**：所有东西都画在同一张纸上；粒子不是叠在画面上的 UI 层，而是纸上的金粉/石墨尘，受同一镜头和同一透视影响。
2. **同一束光**：粒子高光方向与低太阳一致（左上亮、右下暗）；粒子不出现冷色自发光，除非 S05 的 VLM 扫描。
3. **同一条状态变化**：假“完成”章不是被切掉，而是**失水、褪色、碎成粒子**，再被“未完成”章压住；材料转化承担叙事，而不是换一张图。
4. **粒子只在测量发生**：规格虚影、扫描幕、接触图、纠正幽灵、落点下划线；环境尘只是氛围，不参与证据。没有“随便飘一点粒子好看”。
5. **S05 的唯一例外**：环境从 1.0 压到 0.62，纸纹变暗，粒子透明度 +0.15；这是 VLM“看见”的时刻，也是 B3 暗场语法的合法出场。11.15 秒后回到 0.85，S06 回到 1.0。
6. **反例**：水彩背景 + 蓝色科技 HUD + 左右分屏，就是拼接，直接否决；把 B3 的心/房子/人搬来，也是拼接，否决。

### 10.3 时间与确定性

- 项目时间以秒为交换单位；只在 Composition 边界 `frame/fps` 转一次；不在组件中间混用帧和秒。
- 场景半开区间 `[start,end)`；本卡 7 个场景无重叠，不需要 `overlap_with`。
- `draw(t)` / `useCurrentFrame` 的输出只由 `t`、固定资源、seed 决定；禁止 `Date.now`、`Math.random`、`x += v`、上一帧画布残留。
- 粒子目标、纸纹、墨线抖动在模块加载时用种子生成一次；seek 任意帧结果一致。
- 检查顺序：0 → 末 → 中 → 0 → 中，比较同一时间的像素/状态。

### 10.4 性能

- 粒子峰值约 3500，两段拖尾 = 7000 次 sprite draw/帧；用预渲染 32×32 径向 sprite，禁用 `shadowBlur`。
- 水彩/纸纹只缓存，不逐帧做 `feTurbulence`；SVG 滤镜只用于静态 wash 的一次生成。
- 1920×1080、1x DPR；如仍掉帧，先减 S05 接触图到 1200、扫描幕到 2000，不降整片分辨率。
- 粒子层单独 Canvas，文字/印章在 DOM/SVG 层，避免每帧重排文字。

### 10.5 字体与素材

- 需要文件：Noto Serif SC Regular/SemiBold/Bold（或思源宋体同字重），放在 `public/fonts/`，用 `FontFace` 加载；加载完成前 `delayRender`，失败 `cancelRender`。
- 本机现状：未安装 Noto Serif SC；有 SimSun/STSong/微软雅黑。预览可回落 STSong，但最终交付需作者提供可再分发字体。
- **待核**：全片用字 cmap；`≠`、`−`、`°`、`·` 是否在字族内；数字 tabular 是否真实支持。
- 不需要外部图片；纸纹/水彩/齿轮/机械臂全部程序化或 SVG 绘制。音频素材未准备。

### 10.6 音频

- `AudioTracks` 根层放一次；music/sfx 分轨；无口播，暂不启 ducking（保留接口）。
- `sfxTrack` 按“接触 − peakOffset”放置；peakOffset 必须实测后填，不能套常数。

### 11.3 动画阶段

- S02→S03 齿轮圆匹配：接触帧是否同一尺寸/同一圆心；夹爪释放是否滑步。
- S03 盖章回弹：纸面 2px 是否过冲一次；镜头是否误晃。
- S04 焦点转移：印章→缝的 0.45 秒是否晕；缝是否被水彩吃掉。
- S05 扫描：线速度是否匀速、证据是否按经过顺序落、粒子是否遮账本。
- S06 幽灵锁定：旋转/平移方向是否与 +23° / 内推 6.2 mm 一致；真实齿轮是否保持错误。
- S07 文字：最后字落稳时间、读窗、下划线是否在 `≠` 处正确断开。

### 11.4 声音阶段

- E07 印章 press 与纸面回弹同刻；E17 判决 gong 与章落同刻；E20 锁定 click 与幽灵到位同刻。
- 扫描 tick 不盖账本阅读；结尾不出现胜利终止。
- 所有 peakOffset 实测后再填；机器峰值不等于听感。

# DeepSeek Harness 通用代码动画制作 Prompt（用于网页生成任务后）

> 本模板可直接复制使用，但**更推荐**先在 Motion Atlas 网页勾选风格、填写内容，然后点「复制制作指令」生成包含准确 ID、SHA 和原文路径的个性化 Prompt。

你是我的代码动画导演、动效设计师和工程师。请使用当前项目中的 `fy-code-animation` Skill，严格在我授权的阶段内工作，按创作流程产出真实可复现结果。

## 我给你的任务

- 视频要表达的主题或完整文案：`【填写你的文案/内容】`
- 风格编号：`【填写网页选中的 ID，例如 L42、B3】`
- 画面比例：`16:9`
- 时长目标：`30 秒`
- 声音：`先设计四套不同的音乐方案和音效，未经我选择不定稿`
- 当前阶段：`card`（首次只交分镜任务卡；后续我会显式授权 still/audition/final）
- 其他要求：`中文大字体、避免逐句 PPT、镜头节奏有变化、画面与文案有明确的对应关系`

## 正确使用 Skill

1. 通过 DSH 的 skill 系统真实加载 `fy-code-animation`，阅读 `.dsh/skills/fy-code-animation/SKILL.md` 和这次必要的模块。不能只口头声称已加载。
2. 风格库根目录为本项目 `./style-library`（包含 `风格提示词`），运行：

```bash
python .dsh/skills/fy-code-animation/scripts/style_library.py build --root ./style-library
python .dsh/skills/fy-code-animation/scripts/doctor.py --root ./style-library
```

3. 对我的每个风格编号调用风格检索或直接读取对应原始 Markdown，输出其真实路径、SHA、关键的运动、材质、配色与限制，不能只引用短名称。使用多个风格时按时间段明确分配，解决视觉连贯性。
4. 按 Skill 的 `modules/meaning.md`、`modules/workflow.md`、`modules/decisions.md` 和其他适用模块处理原文语义、分镜、文字、镜头、背景、音效和质量。
5. 若现在是 `card`：只产出 `task.json`、分镜表和四案声音规划，**不**渲染视频、不生成音频、不额外安装依赖。
6. 若之后授权 `still`：只按我指定的镜头生成静帧，验证中文排版和视觉语言。
7. 若之后授权 `audition`：根据实际声音工具能力给出四个可试听的方案；如缺工具则标注缺项，不要虚构音轨。
8. 若之后授权 `final`：在独立 `productions/<作品名>/` 创建源码，优先使用可 seek 的确定性时间轴，按实际环境选择 Remotion/HTML/Canvas，导出可打开预览和 MP4；音频需要我先确认选择，质量检查不能省略。
9. 文案细节、完整原始提示词和当次明确要求优先于默认示例。未经我允许，不能发布、购买服务、推送公开仓库、上传私人文案或素材。

## 审核标准

任务必须不仅是「一行大字 + 一个图标 + 淡入」。每镜头需要有明确的对象状态变化、因果关系或视觉表达。字幕清晰、字体统一、不能裁切，转场前后有实际接缝逻辑；速度有快慢变化，必要时允许留白。声音需要真实检查，不能编造已卡点。

## 交付格式

- 所读 Skill 与风格 Markdown 文件及 SHA
- 对全文意义与视觉策略的简述
- 结构化分镜表（开始/结束、画面、动作、字幕、转场、声音需求）
- 本阶段授权内的真实文件与路径
- 运行方法、测试命令、检查结果与问题
- 需要我下一步确认的最少决策项

开始先读取文件和运行自检，再给我当阶段的真实结果。
